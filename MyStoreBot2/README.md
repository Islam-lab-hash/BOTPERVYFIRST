## ЗАПУСК БОТА

### 1. Установите Python 3.10+

### 2. Распакуйте архив

### 3. Установите зависимости:
```bash
pip install -r requirements.txt
```

### 4. Запустите бота:
```bash
python bot.py
```

## КОМАНДЫ

| Команда | Что делает |
|---------|------------|
| /start | Главное меню |
| /myid | Показывает ваш Telegram ID |
| /admin | Админ-панель (только для админов) |

---

## АДМИН-ПАНЕЛЬ (/admin)

### Функции:
- **Товары** - добавить/удалить товары
- **Категории** - управление категориями
- **Заказы** - просмотр и управление заказами
- **Тексты** - редактирование текстов магазина
- **Реквизиты** - реквизиты для оплаты
- **Статистика** - статистика магазина
- **Рассылка** - рассылка пользователям
- **Администраторы** - управление админами (только суперадмин)

---

## РЕДАКТИРОВАНИЕ

### Изменить тексты:
1. /admin → Тексты магазина
2. Выберите текст для изменения

### Изменить реквизиты:
1. /admin → Реквизиты
2. Введите новые данные

### Добавить товар:
1. /admin → Товары → Добавить товар
2. Выберите категорию
3. Введите данные товара
4. Прикрепите фото
